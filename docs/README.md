# Documentação do Bytech Agenda

- `auditorias/`: relatórios técnicos e verificações.
- `releases/`: notas de versões e estabilização.
- `sprints/`: histórico das entregas por sprint.
- `ajustes/`: correções e mudanças pontuais.
- `modulos/`: documentação específica dos módulos.
- `deploy/`: PostgreSQL, publicação e infraestrutura.

Os documentos antigos foram preservados e apenas reorganizados.
